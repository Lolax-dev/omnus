# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed
- PR-only CI added (ubuntu-latest release-file check on pull requests to `main`/`dev`). Feature-merge notifications on squash into `dev`.

## [0.1.1] - 2026-07-21

### Added
- First public multi-platform beta: native installers for Windows, macOS Apple Silicon, and Intel Macs.
- Optional BYO-Cloud sync across devices via the user's own drive; fully local use still works without it.

### Changed
- Public GitHub distribution for the proprietary Omnus study workspace (spaces, documents, notes, tasks, calendar, BYO-Key AI).

## [0.1.0] - 2026-06-02

### Added
- Initial Windows beta: spaces and topics, native PDF workflow with drag-and-drop, notes and tasks, BYO-Key AI (no subscription).
